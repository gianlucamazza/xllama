The following is a technical overview of heterogeneous computing architectures used in modern consumer hardware. Heterogeneous computing refers to systems that use more than one kind of processor or core. These systems gain performance or energy efficiency by adding dissimilar coprocessors, usually incorporating specialized processing capabilities to handle particular tasks. In game consoles such as the Xbox Series S and PlayStation 5, custom SoCs combine general-purpose CPU cores based on the AMD Zen 2 microarchitecture with RDNA 2 GPU cores in a unified memory configuration. The Xbox Series S allocates roughly 10 GB of GDDR6 memory shared between the CPU and GPU, of which approximately 8 GB is accessible to user-mode Dev Mode applications. This unified memory architecture simplifies data movement between CPU and GPU workloads compared to discrete GPU configurations that require explicit PCIe DMA transfers. For machine learning inference workloads, the key bottleneck is typically memory bandwidth rather than raw compute, since transformer models spend a significant fraction of decode time reading weight matrices from DRAM. The Xbox Series S GDDR6 provides approximately 224 GB/s of bandwidth, which compares favourably with desktop DDR4 platforms and enables reasonable throughput for quantized large language model inference in the Q4_K_M quantization regime.
