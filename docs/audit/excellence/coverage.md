**PASS for the captured scope:** [proof](evidence/restore-proof.json) verifies 22
original file hashes, 37 fixture deletions, actual original VAE bytes, and pinned
default-model bytes. The app is stopped, API disabled as at entry, and the audited
package 1.6.0.1102 retained. Initial running state and complete untouched model-tree
hashes were not captured; they are not included in the proof.
