## Security threat model and operational diagnostics

Snapshot: 16a58a995ded56bc40e38a9e2234c490681d41b5. Assets are prompts, generated content, preference records, local model weights, console resources, publisher identity and package integrity. Trust boundaries are the operator and peers on the private LAN, the browser origin and the UWP listener, LocalState and the packaged catalogue, model hosts and the downloader, generated tool proposals and the external executor, and the build service and release consumer. Console Developer Mode assumes a trusted operator. The Store capability manifest has a different network boundary. Report suspected vulnerabilities privately under SECURITY.md.
