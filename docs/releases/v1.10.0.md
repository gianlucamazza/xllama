# xllama v1.10.0

Independent project, not affiliated with or endorsed by Microsoft. Xbox and
Xbox Series S|X are trademarks of the Microsoft group of companies.

This Developer Mode release is about the LAN API and sessions. A new
conversation that shares a long system prompt with an earlier one no longer
starts from scratch on hybrid models, and a client that disconnects during a
streamed tool proposal frees the console. Clients can also send `top_k` and
`repetition_penalty`, and `/health` says which llama.cpp the build carries.

## Sessions

- On hybrid models (LFM2, Granite-4.0-H), a long prompt now leaves prefix
  checkpoints every 512 tokens to 2048, then at doubling distances, besides
  the one just before its end. A later prompt that shares only part of it
  resumes from the longest checkpoint it still shares: a new conversation
  with the same system prompt and tools, a client changing its tools, or a
  re-rendered turn. On Series S with `lfm25-8b-a1b`, a second conversation
  that shares a ~1.2k-token system prompt reuses 1024 tokens
  (`cached_tokens`) and answers in 5.0 s instead of 25.4 s.
  The checkpoints are small on LFM2 (80–160 KiB each). On Granite-4.0-H-Tiny,
  where each is 55 MiB, only the one before the prompt end is kept, as
  before.

## LAN API

The API contract version stays `1`: everything below is a new field or
capability, except the streamed tool-proposal error, which a client should
read as it already reads plain-chat stream errors.

- **Changed:** a tool proposal with `stream: true` now opens its stream
  before generation, as plain chat does. A client that disconnects during a
  long prompt frees the session within seconds. Request errors (bad JSON, an
  unknown model, a prompt too long) are still plain HTTP JSON responses. A
  failure during generation or parsing now arrives as an `{"error":…}` event
  in the stream instead of an HTTP `500`, as it already did on plain chat.
- Chat requests accept `top_k` and `repetition_penalty` (alias
  `repeat_penalty`); `/health` lists them under `sampling`.
- `/health` gains `runtime`: the llama.cpp commit the build was made from and
  the patches applied to it.

## Developer Mode installs

- Installing in place the same package version that is already installed
  leaves the LAN API unreachable (the port drops every connection while the
  app logs `listening`) until a newer revision is installed. `deploy.sh` no
  longer does it unless given `--force-reinstall`. If you see the symptom,
  install a newer revision.

## Measured

- `llama-perplexity`'s HellaSwag scoring was cross-checked against an
  independent implementation of its rule on the same weights and items. The
  two reach the same outcome on 1995 of 2000 items. The catalogue's QAD Q4_0
  quant of `lfm25-350m` scores like its BF16 weights. lm-evaluation-harness's
  prompts score about 0.9 points higher than llama.cpp's text with the same
  rule, so leaderboard figures are not directly comparable. See
  `bench/results/2026-11-27-hellaswag-anchor/`.
