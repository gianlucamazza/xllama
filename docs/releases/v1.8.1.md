Independent project, not affiliated with or endorsed by Microsoft. Xbox and

This Developer Mode release adds an optional D3D12 ROPE path, GPU decode for
more GGUF weight types, Granite 4.x chat formatting, hybrid-cache prefix
snapshots, an optional LCM diffusion scheduler, an optional GGUF thread
count, and keeps Device Portal credentials off the console-script command
line.

## GPU and model handling

- On D3D12, supported plain F32 ROPE can run on the GPU. The option defaults
  to off. See the [GGUF GPU guide](../gguf-gpu-decode.md) for the setting.
  Series S correctness evidence is
  [`d3d12-selftest-d599486-rope-20261124.csv`](../../bench/results/d3d12-selftest-d599486-rope-20261124.csv):
  the self-test rows match the CPU result exactly.
  TODO(validation): logit-parity on the release package is pending on
  Series S after merge (criterion: byte-identical logits in 12/12
  comparisons and `--require-rope` self-test 34/34). No result claimed.
- D3D12 decode now has paths for IQ3_XXS, IQ4_XS and Q5_K weights. Catalogue
  models are unchanged.
- Granite 4.x chat format support; not a catalogue model.

## Session and images

- Hybrid-cache sessions keep an in-memory prefix snapshot after a successful
  prefill and restore it when the next prompt is a strict extension of that
  prefix, so only the suffix is prefilled. Exact regenerate still clears and
  prefills the full prompt. Writing `0` to
  `LocalState\hybrid-prefix-snapshots.txt` opts out. Idea from bjoern2088,
  rebuilt in-tree.
- `LocalState\gguf_n_threads.txt`, when present and positive, sets llama.cpp
  threads for GUI and LAN API GGUF chat. Absent, 0, or an invalid value keeps
  auto-detect. Idea from Chorss, rebuilt in-tree.
- `LocalState\diffuse-lcm.txt` set to `1` uses the Latent Consistency Model
  step table instead of Euler. Absent, the SD-Turbo Euler path is unchanged.

## Console scripts

Device Portal credentials are no longer passed on the command line by the
console scripts.

## Installation and validation

Follow the [installation guide](../install-release.md) and verify the
checksums for the unified MSIX, test certificate and Visual C++ runtime.
Sideload the Developer Mode package. The package retains the
`GianlucaMazza.xllama` identity for in-place updates from earlier packages
with that identity.

The GitHub release attaches the package-bound validation record for Series S.
