## What changed since 1.6.0.0

1.6.0.0 (2026-09-28) added catalogue-backed pulls and GGUF embeddings. 1.7.0
is the work that landed on `main` after that tag: GGUF GPU decode for the
balanced chat model, a coding-tier licence fix, a streaming LAN chat path,
and the public-docs rewrite for a Developer Mode launch.

### LAN API

The LAN API stays **off by default and has no authentication**. Enable it
only on a network you trust. Protocol:
[docs/api-endpoint.md](../api-endpoint.md).

- `POST /v1/chat/completions` accepts `stream: true`. Token pieces travel as
  `chat.completion.chunk` events over `text/event-stream` (assistant role
  first, a finish chunk with `usage`, then `data: [DONE]`). The streamed
  text is raw: stop sequences are withheld from the stream; a client
  disconnect aborts generation (#348).
- A non-empty `tools` or legacy `functions` schema is a **client-side
  proposal**. The reply may contain `tool_calls`. This process does not run
  tools ([ADR 0004](../adr/0004-tool-proposals.md); #334). Grammar follows
  the GGUF template ([ADR 0005](../adr/0005-tool-proposal-grammar.md); #342).
- GUI, chat, embeddings and pull resolve a model the same way: one session
  specification (context, backend, GPU layers, adapter) so a LoRA load no
  longer depends on which surface opened it first
  ([ADR 0007](../adr/0007-session-spec.md); #344).

Request handling:

- The app UI and the LAN API now share one process-wide compute slot, so
  chat, embeddings, image generation, device training and model loading
  run one at a time. While the slot is busy, an API request gets HTTP 503
  (`busy`) and the app shows a busy status; the one exception is a bounded
  wait (up to 15 s) while a model is pre-loading at startup. If a client
  disconnects mid-stream, the generation is aborted and the slot is
  released when it stops. (#354)
- A negative `Content-Length` or a body shorter than declared is rejected
  instead of returning 200. Declared bodies above 8 MiB are 413; a stalled
  head or body times out ([ADR 0006](../adr/0006-http-framing.md); #343).
- Generation numbers (`max_tokens`, `temperature`, `top_p`, `seed`) are
  checked before the model loads. Token counts must be whole and below
  `n_ctx` (#337).
- `usage.prompt_tokens` is the prompt's length, not the tokens prefilled on
  a reused KV prefix (#336).
- A chat or embeddings request that names a model that is not on the
  console returns `404`, not `500`.

While the endpoint is on, the console header shows the base URL, the request
being served, and recent counts, so a pad user can see that the LAN API is
busy (#332).

Image generation uses SD-Turbo. The Image dialog shows **Powered by
Stability AI** at the bottom of its settings, above Generate
([docs/using-the-app.md](../using-the-app.md); #368). That line is a licence
credit, not a partnership or endorsement claim.

licence text in
[LICENSES/stabilityai-sd-turbo-LICENSE](../../LICENSES/stabilityai-sd-turbo-LICENSE)
says it preserves free access for people or organizations generating annual
revenue of less than US $1,000,000 (or local currency equivalent). Commercial
use requires registration with Stability AI; if you or your affiliates
generate more than USD $1,000,000 in annual revenue, the licences granted
under that agreement terminate. Registered under the Community License.

Redistribution also needs a copy of the licence, a Notice file, and the
"Powered by Stability AI" credit (§IV.a). Those files travel with the
re-hosted `models-v1` build (`LICENSES/`, `NOTICE`; #367).

On Series S, the published full-VAE run is **6891.6 ms** total for 512×512,
1 step (text encoder 1006.6 ms, UNet 3328.9 ms, VAE 2556.1 ms) —
[docs/benchmarks.md](../benchmarks.md), source `phase5-diffuse.csv`.

### Diagnostics

- Optional **debug dashboard** (default off): a Settings toggle and/or
  `LocalState\debug-dashboard.flag` shows real resident-model, LAN, and
  inference readings above the prompt. Missing sources render as
  `unavailable`. The chat UI is unchanged while the view is off (#357).
- Both backends log prefill start/done and periodic decode progress. An
  optional stall watchdog can abort a hung prefill or decode (default 180 s;
  0 disables) (#328).

## Limits

- Developer Mode only. Retail games and apps do not run in Developer Mode.
- Tested and measured on Series S. Not yet tested on Series X.
- The LAN API has no authentication.
- Models are third-party and each has its own licence. Some are
  non-commercial or carry a revenue cap. Check the upstream card before use.
- No model is bundled in the MSIX.
