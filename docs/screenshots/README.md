Series S, Developer Mode; not a speed claim.

A 4.7-second cut (three segments) of a 46-second capture made on a Series S in
Developer Mode from Device Portal screenshots. The video doesn't support any
speed claim. The full capture is
[`xllama-demo-v1.5.6.mp4`](xllama-demo-v1.5.6.mp4), the cut points are in
[`demo-manifest.json`](demo-manifest.json), and the demo is driven by
[`demo/demo-script.json`](../../demo/demo-script.json) via
`scripts/capture-demo-video.sh`. A longer
[product showcase](xllama-demo-v1.5.6-showcase.mp4) is driven by
[`demo/demo-showcase-script.json`](../../demo/demo-showcase-script.json).
